# Quantificador de Obra

Web app (PWA) para calcular quantidades de materiais de construção: blocos, cobogós/grelhas, pavê e betão.

- **Modo Simples**: tamanho do espaço + tamanho da peça + junta → número de peças.
- **Modo Completo**: muros (incl. terreno por lados), cobogós, pavê (formas, desenho livre, recortes, lancil, areia) e lajes.
- Funciona offline e instala-se no Android ("Instalar app" no Chrome).

Publicado no Vercel como site estático (sem build).
